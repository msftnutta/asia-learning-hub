# Asia Learning Hub
This repo stores the reusable assets for continuous learning, knowledge sharing, and professional growth across the Asia MTT community.

## Microsoft Learn MCP

This workspace includes the Microsoft Learn MCP server for GitHub Copilot and other MCP-compatible VS Code clients. It provides access to current Microsoft documentation and code samples through the workspace configuration in [.vscode/mcp.json](./.vscode/mcp.json).

After opening the repository in VS Code, approve the workspace MCP server when prompted and use it from an MCP-compatible chat or agent.
