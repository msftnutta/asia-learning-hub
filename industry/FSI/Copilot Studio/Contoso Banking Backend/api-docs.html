Contoso Bank API Reference

A deliberately small API surface for learning common banking transactions.

Base URL: https://<your-app-name>.azurewebsites.net/api  |  Local: http://localhost:8080/api
GET /login?userId=USER001

Demo login and account lookup

This is not authentication. It maps one of the three classroom user IDs to its demo account.

{
  "success": true,
  "userId": "USER001",
  "accountId": "ACC001",
  "owner": "Chihiro Kimura",
  "authenticated": false
}
GET /saved-accounts?accountId=ACC001

List saved demo recipients

Returns the other classroom accounts so a student can choose a transfer recipient without typing an arbitrary account number.

GET /balance?accountId=ACC001

Get account balance

Returns the account owner, current balance, currency, and timestamp.

{
  "success": true,
  "accountId": "ACC001",
  "owner": "Chihiro Kimura",
  "balance": 5280.5,
  "currency": "USD"
}
GET /transactions?accountId=ACC001&limit=10

List transactions

Returns recent transactions for an account.

POST /transfer

Transfer money

Transfers money between two demo accounts after validating both accounts and the sender balance.

{
  "fromAccountId": "ACC001",
  "toAccountId": "ACC002",
  "amount": 45,
  "note": "Dinner"
}
GET /bills?accountId=ACC001

1. List outstanding bills

Call this first to show the customer which bills are available to pay.

{
  "success": true,
  "accountId": "ACC001",
  "count": 2,
  "bills": [
    {
      "billId": "BILL-1001",
      "billType": "ELECTRICITY",
      "billerName": "PowerCo Electric",
      "amount": 85,
      "dueDate": "2026-10-05"
    }
  ]
}
POST /bills/pay

2. Pay a selected bill

The mobile client sends the selected billId; the server owns the amount and biller details.

{
  "accountId": "ACC001",
  "billId": "BILL-1001"
}
GET /vouchers

List available vouchers

Returns the voucher types and denominations a customer can buy. Call this before a purchase so the client never hard-codes the catalog.

{
  "success": true,
  "count": 2,
  "vouchers": [
    {
      "voucherType": "GIFT_CARD",
      "brand": "Contoso Gift Card",
      "category": "Gift",
      "denominations": [25, 50, 100],
      "currency": "USD"
    }
  ]
}
POST /voucher/purchase

Purchase a voucher

The simplified demo supports gift cards and grocery vouchers with fixed denominations.

{
  "accountId": "ACC001",
  "voucherType": "GIFT_CARD",
  "amount": 25
}
